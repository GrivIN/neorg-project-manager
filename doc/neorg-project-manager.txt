1. INTRODUCTION                         *neorg-project-manager-introduction*

neorg-project-manager is a Work Breakdown Structure (WBS) engine for Neorg.
It organizes software projects with hierarchical numbering, cross-file link
resolution, prerequisite tracking, and auto-generated status overviews.

Features:
- Auto-numbering of headings (written into the file, configurable format)
- Custom root numbering (anchor level-1 headings with project-specific numbers)
- Cross-file navigation via `{* number}` links
- Prerequisite tracking with `[BLOCKED]` / `[READY_FOR_IMPLEMENTATION]`
- Mixed-type progress indicators `[done/total]`
- Project status tree in `project.norg` / `index.norg`
- Project-wide file/directory renaming
- Tree fold/toggle (body-only or full collapse in status files)
- Extract to file (move heading content to its own .norg file)
- Heading breadcrumb (statusline, winbar, or virtual text)

==============================================================================
2. REQUIREMENTS                         *neorg-project-manager-requirements*

- Neovim >= 0.10
- Neorg with the `norg` tree-sitter parser installed
- lazy.nvim (recommended)

3. SETUP                                *neorg-project-manager-setup*

Using lazy.nvim: >lua
    {
        "your-username/neorg-project-manager",
        ft = "norg",
        opts = {},
    }
<

Call setup explicitly if not using lazy.nvim's `opts`: >lua

4. COMMANDS                             *neorg-project-manager-commands*

                                        *:NeorgPMRenumber*
:NeorgPMRenumber
    Renumber all headings in the current file and update all `{* number}`
    links to reflect new numbers. Prefix-aware: if the file has a number
    in its filename, headings are numbered relative to that prefix.

                                        *:NeorgPMRenumberProject*
:NeorgPMRenumberProject
    Renumber all files and directories in the project. Updates all links
    across all files. Shows a confirmation prompt if the number of renames
    exceeds `rename_confirm_threshold` (default: 5).

                                        *:NeorgPMStatus*
:NeorgPMStatus
    Update the current `project.norg` or `index.norg` buffer with current
    project state. Uses surgical update on populated files (only modifies
    managed headings). Uses full generation on empty files.

                                        *:NeorgPMStatusAll*
:NeorgPMStatusAll
    Regenerate all `index.norg` files and `project.norg` across the entire
    project tree.

                                        *:NeorgPMToggle*
:NeorgPMToggle
    Toggle body/description folds in the current heading's subtree.
    Hides all non-heading content (descriptions, lists, notes) while
    keeping all headings visible at every level. Shows the tree skeleton.
    Press again to reveal all body content. Only active in `project.norg`
    and `index.norg` buffers where folds are set up.

                                        *:NeorgPMToggleAll*
:NeorgPMToggleAll
    Toggle the full fold at the current heading. Collapses the heading
    with ALL its children (body + sub-headings) into a single line.
    Press again on the collapsed fold to expand everything back.

                                        *:NeorgPMExtract*
:NeorgPMExtract
    Extract a heading's content into its own .norg file. Place cursor on
    a heading with a `{* number}` link in a status file (root-level or
    directory-matching numbered file). The content below the heading moves
    to a new file (with heading levels shifted to start at `*`). The
    heading line stays in place as a navigation link. Numbering is
    preserved. Shows a confirmation prompt.

    Aborts if the entry is already a standalone file or if the target
    file already exists on disk.

    Example: cursor on `*** (-) 1.1.1. Auth {* 1.1.1}` with `****`
    children below → creates `1.1.1. Auth.norg` with those children
    shifted to `*` level.

5. KEYBINDS                             *neorg-project-manager-keybinds*

Default keybinds use `<LocalLeader>` + the configured prefix (default "p").
All keybinds are buffer-local to norg files.

    <LocalLeader>pr     |:NeorgPMRenumber|
    <LocalLeader>pR     |:NeorgPMRenumberProject|
    <LocalLeader>ps     |:NeorgPMStatus|
    <LocalLeader>pS     |:NeorgPMStatusAll|
    <LocalLeader>pt     |:NeorgPMToggle| (body folds — headings only)
    <LocalLeader>pT     |:NeorgPMToggleAll| (full fold — collapse all)
    <LocalLeader>pe     |:NeorgPMExtract|
    <CR>                Number-aware link hop (falls back to Neorg native hop)

Disable default keybinds: >lua
    opts = { default_keybinds = false }
<

Change the prefix: >lua
    opts = { keybind_prefix = "n" }  -- becomes <LocalLeader>nr, etc.
<

Integrates with which-key.nvim if available.

6. CONFIGURATION                        *neorg-project-manager-config*

All options with defaults: >lua
    require("neorg-project-manager").setup({
        -- Feature toggles
        auto_numbering = true,
        mixed_propagation = true,
        prerequisite_tracking = true,
        cross_file = true,

        -- Triggers
        renumber_on_save = true,
        renumber_on_heading_leave = true,

        -- Anchor root headings (preserve user-typed level-1 numbers)
        anchor_root_headings = true,

        -- Numbering format (applied by total depth)
        numbering_styles = {
            "numeric", "numeric", "numeric",
            "numeric", "numeric", "numeric",
        },
        number_separator = ".",
        number_title_separator = ". ",
        number_format = nil,  -- custom function(counters, level, prefix)

        -- Prerequisite detection
        prereq_pattern = "Pre%-requisites:",

        -- Project settings
        project_root = nil,   -- nil = auto-detect via project.norg
        file_prefix = nil,    -- nil = auto-detect from filename
        cross_file = true,

        -- Virtual text
        blocked_highlight = "DiagnosticWarn",
        ready_highlight = "DiagnosticOk",
        mixed_progress_highlight = "Normal",
        blocked_format = function(done, total)
            return string.format("[BLOCKED: %d/%d prereqs done]", done, total)
        end,
        ready_text = "[READY_FOR_IMPLEMENTATION]",
        mixed_format = function(done, total)
            return string.format("[%d/%d]", done, total)
        end,

        -- Keybinds
        default_keybinds = true,
        keybind_prefix = "p",

        -- Rename
        rename_confirm_threshold = 5,

        -- Breadcrumb / heading path
        breadcrumb_display = "statusline",  -- "statusline", "winbar", "virtual", "none"
        breadcrumb_separator = " > ",
        breadcrumb_project_path = true,     -- false for file-only context
        breadcrumb_format = nil,            -- custom function(segments) → string
    })
<

                                    *neorg-project-manager-numbering-styles*
Numbering styles (per total depth):
    "numeric"       1, 2, 3, ...
    "alpha_upper"   A, B, C, ..., Z, AA, AB, ...
    "alpha_lower"   a, b, c, ..., z, aa, ab, ...
    "roman_upper"   I, II, III, IV, ...
    "roman_lower"   i, ii, iii, iv, ...

Example: mixed styles >lua
    numbering_styles = {
        "numeric", "numeric", "alpha_upper",
        "alpha_lower", "numeric", "roman_lower",
    }
    -- Result: 1.1.A.b.1.iv
<

                                    *neorg-project-manager-number-format*
Custom format function: >lua
    number_format = function(counters, level, prefix)
        local pm = require("neorg-project-manager.numbering")
        local parts = {}
        for i = 1, level do
            parts[i] = pm.format_counter(counters[i], "roman_upper")
        end
        local num = table.concat(parts, ".")
        if prefix then return prefix .. "." .. num end
        return num
    end
<

7. HIGHLIGHTS                           *neorg-project-manager-highlights*

The plugin defines these highlight groups (override with |:highlight|):

    NeorgPMBlocked                      *NeorgPMBlocked*
        Default: links to `DiagnosticWarn`
        Used for `[BLOCKED: X/Y prereqs done]` virtual text.

    NeorgPMReady                        *NeorgPMReady*
        Default: links to `DiagnosticOk`
        Used for `[READY_FOR_IMPLEMENTATION]` virtual text.

    NeorgPMProgress                     *NeorgPMProgress*
        Default: links to `Comment`
        Used for `[3/5]` progress virtual text.

Override example: >lua
    vim.api.nvim_set_hl(0, "NeorgPMBlocked", { fg = "#ff0000", bold = true })
<

8. EVENTS                              *neorg-project-manager-events*

The plugin fires User autocmd events:

    NeorgPMAttach                       *NeorgPMAttach*
        Fired when the plugin attaches to a norg buffer.

    NeorgPMRenumber                     *NeorgPMRenumber-event*
        Fired after renumbering completes (via command or auto-trigger).

Example: >lua
    vim.api.nvim_create_autocmd("User", {
        pattern = "NeorgPMRenumber",
        callback = function() print("Renumbered!") end,
    })
<

9. PROJECT STRUCTURE                    *neorg-project-manager-structure*

A project is identified by a root-level numbered file — a `.norg` file
whose prefix has no separator (depth 1), e.g., `42. ACME App.norg`.

    <N>. <title>.norg            Root status file (depth-1 prefix = root marker)
    <N.M>. <title>.norg          Content/companion file
    <N.M>. <title>/              Numbered directory
    <N.M>. <title>/<N.M>. *.norg Directory status file (prefix matches dir)

File prefixes:
    "42. ACME App.norg"      → prefix = "42" (depth 1 = root marker)
    "42.1. Auth.norg"        → prefix = "42.1"
    "notes.norg"             → prefix = nil (no number)

Headings inside a file are numbered from the prefix:
    File "1.1.3.1. Stage 1.norg":
    * heading → 1.1.3.1.1
    ** heading → 1.1.3.1.1.1

                                    *neorg-project-manager-managed-headings*
Managed vs manual headings:
    Managed = has a `{* number}` link → auto-updated by the plugin
    Manual  = no such link → never touched

10. AUTOMATIC BEHAVIOR                  *neorg-project-manager-behavior*

The plugin auto-modifies files only under these conditions:

Auto-renumber on save:
    Only if the file is inside a project (has `project.norg` ancestor)
    OR already contains numbered headings.

Auto-update index.norg / project.norg:
    Only when a content file inside a project is saved.
    Uses surgical update (only managed headings change).

Standalone unnumbered files:
    Files with no numbered headings and no project root are left
    completely untouched. Personal notes, journals, and non-project
    files are safe.

Disable auto-renumber: >lua
    opts = { renumber_on_save = false, renumber_on_heading_leave = false }
<

Disable per buffer: >lua
    vim.b.neorg_pm_disabled = true  -- set before FileType fires
<

11. API                                 *neorg-project-manager-api*

Public functions for programmatic use:

numbering module:
    `format_counter(counter, style)`        Format a number in a style
    `format_number(counters, level, prefix)` Build a full number string
    `format_prefix_for_position(parent, pos)` Get prefix for Nth item
    `parse_number_and_title(text)`          Split number from title
    `get_file_prefix(buf)`                  Get prefix from filename
    `build_number_index(buf)`               Build number→line map
    `renumber(buf)`                         Renumber all headings
    `update_links(buf, old_to_new)`         Update links in buffer

helpers module:
    `get_todo_state(node)`                  Get todo state from TS node
    `get_heading_level(node)`               Get heading level (1-6)
    `get_list_level(node)`                  Get list level (1-6)
    `get_norg_root(buf)`                    Parse buffer, get root node
    `replace_link_numbers(lines, fn)`       Replace links with resolver
    `prefix_depth(prefix)`                  Count depth of a prefix
    `extract_link_number_from_line(line)`   Extract {* N} from line
    `natural_sort_prefixes(a, b)`           Natural sort comparator

project module:
    `find_root(filepath)`                   Find project.norg ancestor
    `extract_prefix(name)`                  Get prefix from filename
    `scan(root)`                            Scan project tree
    `resolve_number_to_file(number, entries)` Longest prefix match

status module:
    `aggregate_state(states)`               Aggregate child states
    `build_directory_tree(dir)`             Build status tree
    `build_project_tree(root)`              Build full project tree
    `render_as_norg(tree, opts)`            Render tree as norg lines
    `update_file(path, scope, type)`        Surgical update on disk
    `update(buf)`                           Surgical update in buffer
    `generate(buf)`                         Full generation in buffer

fold module:
    `setup_folds(buf)`                      Activate folds for status file
    `toggle_body(buf)`                      Toggle body folds (headings only)
    `toggle_all(buf)`                       Toggle full fold (collapse all)
    `is_status_file(buf)`                   Check if buf is status file

extract module:
    `extract(buf)`                          Extract entry to file
    `resolve_target_number(buf)`            Resolve number from cursor
    `locate_entry(number, root)`            Find entry in project

breadcrumb module:                      *neorg-project-manager-breadcrumb*
    `get()`                                 Get heading path string
    `setup_winbar(buf)`                     Activate winbar display
    `setup_virtual_text(buf, ns)`           Activate virtual text display

    The `get()` function returns the current heading path as a string.
    Results are cached per {buffer, cursor line, changedtick} — safe to
    call on every statusline redraw.

    Display modes:
        "statusline"  User calls `get()` from lualine config (default)
        "winbar"      Shown at top of window via vim.wo.winbar
        "virtual"     Shown as virtual text on current heading line
        "none"        Disabled (get() still works if called manually)

    Lualine example: >lua
        sections = {
            lualine_c = {
                { require("neorg-project-manager.breadcrumb").get,
                  cond = function() return vim.bo.filetype == "norg" end },
            },
        }
<
